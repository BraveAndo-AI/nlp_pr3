# Инструкция для аннотаторов (v1)

## Задача
Классификация казахских веб-текстов по **пригодности для обучения языковой модели**.
Это нужно для проекта: на хороших текстах дообучаем LLM через LoRA, мусор отбрасываем.

Читай **весь фрагмент** (до 1500 символов) и ставь **одну** метку.

## Метки

### GOOD — хороший текст
Связный текст на **казахском**, который можно было бы дать модели как пример «правильного языка».
- законченные предложения, понятный смысл (новость, статья, рассказ, инструкция, объяснение);
- грамотность нормальная, единичные опечатки допустимы;
- русских/английских вставок немного (отдельные термины, названия).

### MEDIUM — можно использовать, но с оговорками
Текст в целом казахский и связный, но есть **заметный** недостаток:
- много русских вставок, но казахский всё ещё основной (> ~50 % текста);
- примерно половина — шаблонный мусор сайта (меню, «Барлық жаңалықтар», куки, контакты), а остальное — нормальный текст;
- очень короткий содержательный кусок (1–2 предложения) среди служебного текста;
- текст похож на машинный перевод, но читается.

### BAD — мусор
- в основном **не казахский** (русский, английский, транслит латиницей);
- список ссылок, тегов, товаров, цен без связного текста;
- повторы, обрывки, бессмысленный набор слов, сломанная кодировка;
- спам, реклама казино/ставок, контент 18+;
- машинный перевод, который невозможно понять.

## Правила для спорных случаев
1. **Сомневаешься между двумя метками — ставь более низкую** (GOOD/MEDIUM → MEDIUM, MEDIUM/BAD → BAD).
2. Оцениваешь **качество языка**, а не тему: политика, реклама услуг, религия — это не повод для BAD, если текст связный.
3. Устаревшие/фактически неверные сведения не влияют на метку.
4. Если не уверен — оставь короткий комментарий: он нужен для разбора расхождений.

## Примеры
| Фрагмент (сокращено) | Метка | Почему |
|---|---|---|

| «Басты бет · Жаңалықтар · Байланыс … Бүгін қалада жаңа саябақ ашылды. © 2023 Барлық құқықтар қорғалған» | MEDIUM | одно содержательное предложение, остальное — меню сайта |

| «Сегодня в Астане прошла встреча, на которой обсудили…» | BAD | текст на русском |
| «Мен бүгін жұмысқа бардым, но там ничего не было, сондықтан үйге қайттым…» | MEDIUM | разговорный текст с сильным смешением языков |

## Процедура
1. Раунд 1: 200 текстов, каждый аннотатор размечает **независимо**, не обсуждая.
2. Считаем κ и α (`agreement.py`), разбираем все расхождения вместе.
3. Уточняем инструкцию → **v2** (раздел ниже), фиксируем, какие правила добавлены.
4. Раунд 2: новые 100 текстов по v2, снова считаем κ и α.
