# Datasheet: казахский веб-корпус KazWeb-6K

Формат по Gebru et al., «Datasheets for Datasets». Значения в `[квадратных скобках]` взять из `collect_log.json` и `stats.json`.

## 1. Мотивация
- **Зачем создан:** исследовательский корпус для индивидуального проекта по адаптации LLM к казахскому языку методами PEFT (LoRA): статистический анализ, отбор качественных текстов, разметка качества.
- **Кто создал:** Мәжит Арнұр, докторант [кафедра, университет], 2026.
- **Финансирование:** нет.

## 2. Состав
- **Экземпляр:** один веб-документ (статья, новость, страница сайта).
- **Количество:** [сохранено] документов, [токенов N] токенов, [типов V] словоформ.
- **Поля JSONL:** `id`, `text`, `source`, `url`, `date` (дата обхода Common Crawl), `license`, `lang`, `n_words`.
- **Языки:** казахский (кириллица) — [доля kk]; русский — [доля ru]; английский — [доля en] (по fastText lid.176, на уровне абзацев).
- **Выборка:** это не весь казахский веб, а первые [просмотрено] документов потока FineWeb-2 `kaz_Cyrl` после фильтрации. Нерепрезентативна по жанрам: преобладают новости и сайты организаций.
- **Метки:** 300 документов размечены по качеству (GOOD / MEDIUM / BAD), см. `annotation/`.
- **Персональные данные:** веб-тексты могут содержать имена, e-mail и телефоны. Отдельная анонимизация не проводилась — **не публиковать корпус целиком без неё**.
- **Нежелательный контент:** возможен остаточный спам/реклама, несмотря на фильтры.

- **Период текстов:** даты обхода Common Crawl [min date – max date по полю `date`].
- **Дата сбора:** [дата запуска].

## 4. Предобработка
1. Нормализация пробелов и пустых строк.
2. **Фильтр мусора** (`junk_reason`): длина 50–20 000 слов; ≥ 60 % букв; ≤ 30 % повторяющихся строк; не больше 1 ссылки на 20 слов; стоп-слова спама; средняя длина слова 3–12. Отброшено: [мусор: … из collect_log.json].
3. **Точные дубли:** SHA-1 от нормализованного текста. Отброшено: [точный дубль].
4. **Почти-дубли:** MinHash (128 перестановок, словные 5-граммы) + LSH, порог Jaccard ≥ 0.8. Отброшено: [почти-дубль].
- Сырые данные не сохраняются: их можно восстановить из FineWeb-2.

## 5. Использование
- **Для чего:** частотный анализ, обучение/оценка фильтров качества, продолженное обучение небольших LLM на казахском.
- **Не подходит:** как эталон литературного языка (веб-тексты, есть ошибки и смешение языков); для выводов о мнениях населения.

## 6. Распространение и лицензия
- **Лицензия:** ODC-By 1.0 (как у FineWeb-2) + условия использования Common Crawl. При использовании нужно указать источник.
